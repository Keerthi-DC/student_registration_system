# 🎓 Student Registration System

A modern, fully responsive **Student Registration System** built with vanilla HTML, CSS, and JavaScript.  
All data is persisted in the browser's **LocalStorage** — no backend required.

---

## 🚀 Features

| Feature | Details |
|---|---|
| **Register Students** | Add name, student ID, email and contact number |
| **Edit Records** | In-place editing with the same form |
| **Delete Records** | Confirmation modal before permanent deletion |
| **Local Storage** | Data survives page refresh / browser close |
| **Live Search** | Filter records instantly across all fields |
| **Column Sorting** | Click any column header to sort ascending / descending |
| **Dynamic Scrollbar** | Vertical scrollbar added via JS when rows exceed 5 |
| **Input Validation** | Name (letters only), ID (numbers), email (valid format), phone (min 10 digits) |
| **Toast Notifications** | Success / error / info feedback messages |
| **Fully Responsive** | Mobile (≤640px) · Tablet (641–1024px) · Desktop (≥1025px) |

## 🛠 How to Run

1. Clone or download the repository  
2. Open `index.html` in any modern browser  
3. No build step, no dependencies, no server needed

```bash
git clone https://github.com/Keerthi-DC/student_registration_system.git
cd student_registration_system
# Open index.html in your browser
```
